# AFT Fathom

> AFT Fathom keeps a pipe network, its pumps, and the loss results on one model so a branch can be judged without a second workbook.

---

## Session Card

| Slice | What you do in AFT Fathom | What remains |
|-------|---------------------------|--------------|
| Arrival | Open AFT Fathom and name the pipe system for this review | A titled network |
| Focus | Keep live pipes and pumps on the AFT Fathom branch flow view | A short active set |

| Handoff | Mark the branch that still needs a design note | A note for the next visit |

## Four Beats

1. **Name the job.** Give the AFT Fathom network a short title before you add pipes.
2. **Pin the live set.** Keep only the lines in this case on the model.
3. **Check once.** Read pump and loss results before a large edit.
4. **Close the loop.** Leave a design note so the next visit does not start from a search.

## First Questions

**Does AFT Fathom replace every other program?**  
No. AFT Fathom sits beside CAD and the files you already use.

**Can two people share one computer?**  
Yes. Each person keeps a separate AFT Fathom network file.

**What should a new user try first?**  
One short pipe loop today, then the same model tomorrow.

## Who Sits Down at AFT Fathom

- **Plant work** — live lines stay on the AFT Fathom model.
- **Study** — a small loop is enough for a first pass.
- **Handoff** — the next person reads the design note, not a tour.

## Field Note

AFT Fathom is easier to trust when the model stays smaller than the folder of old cases. Name the network, keep the live branches, and write which loss still matters. That note is the path back, not a copy of every pipe.

## One Real Pass

Pick one loop that already has a name. Open it in AFT Fathom, keep only those pipes, and finish one visible check. Extra systems wait for their own title.
